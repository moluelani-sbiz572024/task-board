# task-board

## 概要
タスクを管理できるシンプルなタスクボードアプリです。

- テキスト入力でタスクを追加し、チェックボックスで完了・未完了を切り替え、削除できる
- 完了済みのタスクはグレーで表示する
- タスクはローカルストレージに保存され、ページをリロードしても消滅しない

## 機能
- テキスト入力でタスクを追加する
- チェックボックスで完了・未完了を切り替えることができる
- タスクを削除することができる
- 完了済みのタスクは、グレーで表示する
- タスクをローカルストレージに保存し、ページをリロードしても消滅しない

## 技術スタック
- React 18
- Vite 5

## 開発コマンド
- `npm install`：依存パッケージのインストール
- `npm run dev`：開発サーバー起動
- `npm run build`：プロダクションビルド
